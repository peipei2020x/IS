# Ambient Monitor Display

作業中やリラックスタイムに、モニターの端で流しておくための「環境映像」時計です。
12種類＋カスタム可能なビジュアルエフェクトを搭載し、ブラウザさえあればどこでもデジタルインテリアとして機能します。

## 📋 特徴
* **12種類のテーマ**: パーティクル、デジタルレイン、オーロラ、DVDバウンスなど、気分に合わせて切り替え可能。
* **カスタムCSS対応**: 画面上のエディタから直接デザインを調整し、設定をURLとして保存可能。
* **ゼロ・ディペンデンシー**: 外部ライブラリや外部サーバーへの通信を一切行わないため、軽量かつ安全です。
* **レスポンシブ**: デスクトップPCから古いタブレットまで、画面サイズに合わせて自動調整されます。

## 🚀 使い方
1. `index.html` をブラウザで開きます。
2. 右下の **[▣ DISPLAY]** ボタンをクリックしてメニューを表示します。
3. 好きなシーンを選択するか、**[🎨 CUSTOM]** から独自のCSSを適用してください。

## 🎨 カスタマイズ例
付属のAI用プロンプト集をコピーしてChatGPTやClaudeに貼り付けることで、自分好みの色や雰囲気に簡単にアレンジできます。
